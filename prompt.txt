# Task: Develop a polished mobile-friendly Tetris game using TypeScript + Canvas + PWA

## Project Goal

开发一个可以在 Android 手机上直接运行的单机俄罗斯方块游戏。

最终目标：

1. 用户无需安装 APK，通过浏览器访问即可游玩。
2. 支持 Android 手机触控操作。
3. 可以通过 "添加到主屏幕" 作为 PWA 独立运行。
4. 游戏体验接近成熟商业俄罗斯方块游戏，而不是简单 demo。
5. 代码结构清晰，方便后续扩展。


---

# Technology Stack (Mandatory)

必须采用：

- TypeScript
- HTML5 Canvas
- Vite
- PWA


禁止：

- React
- Vue
- Unity
- Flutter

原因：

俄罗斯方块属于实时 Canvas 游戏，不需要 DOM UI 框架。

推荐工程：

```

│
├── rendering/

```

# Core Gameplay Requirements

实现完整俄罗斯方块玩法。


## Board

标准：

```
10 columns
20 visible rows
+ hidden spawn rows
```

要求：

- grid based
- 每个 cell 独立管理
- 支持颜色主题


---

# Tetromino System

实现标准7种方块：

```
I
O
T
S
Z
J
L
```


要求：

- 使用矩阵表示
- 支持旋转
- 支持碰撞检测


旋转规则：

优先采用：

- Tetris Guideline 风格
- SRS (Super Rotation System)

如果复杂度过高：

实现简化版旋转，但代码结构需要方便未来替换。


---

# Random Generator

不要简单 random。


实现：

- 7-bag randomizer

即：

每个bag包含：

```
I O T S Z J L
```

随机打乱。


优势：

避免长期没有某种方块。

# Movement System

必须支持：

## 自动下降

gravity system:

```
time ->
piece moves down
```


## 玩家控制

键盘：

```
Left
Right
Down
Space = hard drop
Up = rotate
P = pause
```


手机：

必须支持：

- 左滑：左移
- 右滑：右移
- 下滑：soft drop
- 点击：旋转
- 长按下降


同时提供虚拟按钮：

```
+----------------+

   GAME BOARD


[←] [ROTATE] [→]

       [↓]

       [DROP]

+----------------+
```

- piece landing
- lock delay

不要立即固定。

参考现代游戏：

```

wait ~500ms

if player moves
reset timer

otherwise lock
```
